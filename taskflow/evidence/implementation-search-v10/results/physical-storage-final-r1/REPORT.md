# Fresh18 physical storage audit

Read-only independent correlation of compiled-final-r3. No build, NPU execution or package edits. Helper copied from storage-path-review-r2; exact new helper hash and all source/package/readelf hashes retained. Detailed ledger: physical-paths.json; compact totals: summary.json.

Passed across 18 packages:82 actual runtime compute stages and282 tensor-task path records. Verified actual program ELF SHA equals compile/storage record, runtime audit source/plan/ABI hashes, host ABI argument count and f32 shape bytes/roles, linker script SHA, actual ELF buffer/stack symbol addresses, payload equals planned stage payload and fits24576B policy. Each runtime task correlates storage/ABI argument to shim DMA channel, explicit circuit OR packet flow, compute port, and every local full/tail BD buffer in the cyclic BD chain. Every actual compute core .text occurs in its stage PDI, and that complete stage PDI occurs in the actual program ELF. Core ELF/readelf commands/outputs are retained.

Maximum stage payload18432B; unplanned local payload0B; reserved stack4096B. These are stage-local allocations, not sum across sequential stages and not a single-bank capacity assertion. Linker bank windows and buffer addresses are recorded per stage:24576B is the compiler's logical pool payload policy, not a physical24KiB bank. Stack reservation is not measured stack high-water; successful target linker allocation remains authoritative. No extra nonempty nontext allocated core ELF sections were found by the recorded section audit; this does not count opaque hardware/runtime storage.

Exactly2 tail packages have planned channels and bind successful native independent channel checker plus final emitted-port audit. The other16 packages have no planned legalization: channel-check status is explicitly not-applicable, NOT a claimed passed channel test. Static path correlation still covers their generated ports/BDs.

No row1 tile declarations, row1 buffers, memtile_dma operations, objectFIFO declarations or circuit/packet row1 endpoints appear in these final module views. The observable tensor path is ABI system BO↔shim↔compute localspace2 via streams. This is NO evidence of hidden L2/memtile allocation, persistent hardware bypass, on-wire DDR bytes or traffic counters. Architecture logical links and physical fabric microarchitecture are different abstractions. Any additional undocumented DMA/FIFO/runtime buffering remains unknown.

Tail tools additionally generated18 reset-named linker artifacts absent from the runtime tensor ledger. They are listed/bound separately, not silently counted as planned compute stages or asserted as standalone reset-PDI embeddings. The first old helper assumption (circuit-only routes) was invalid for tail packet flows; the replacement accepts only explicit one-source/one-destination packet declarations and still requires unique path+matching storage across ALL BD templates. The other old assumption (all generated ELF/PDI directories are actual runtime tensor stages) was invalid for reset artifacts; exclusions are explicit and auditable.

This audit proves static package consistency within the stated projections. It does not independently re-prove source arithmetic, numerical results, FIFO deadlock freedom, actual command completion, stream sequence under execution, packet header bandwidth, physical DDR counts, or runtime progress/trace. Root's separate fresh train/holdout device results and numerical audits remain the execution evidence. It does not reassign old ELF measurements to new packages.
